# steam-block

[![npm version](https://img.shields.io/npm/v/steam-block.svg)](https://www.npmjs.com/package/steam-block)

> A dependency free web component for hero and split content and media sections, styled entirely through CSS custom properties. No build step, no framework, no configuration object, just a custom element and a script tag.

[Full documentation and live examples →](https://steam-block.stimulies.be/)

## Install

```bash
npm install steam-block
```

```js
// Optional, must come first: import 'steam-block/dist/steam-emerge.js'
import 'steam-block/dist/steam-block.js'
```

Or skip npm entirely and load it straight from a CDN:

```html
<script src="https://cdn.jsdelivr.net/npm/steam-block@1.1.0/dist/steam-block.js" integrity="sha384-iQB69ION+fOI85hIazKAsDqsORX4sV3IemwxcTiqslH/JsGXlJly9as9oMh12ob8" crossorigin="anonymous" defer></script>
```

Want the optional scroll reveal helper too? Load `steam-emerge.js` before `steam-block.js`:

```html
<script src="https://cdn.jsdelivr.net/npm/steam-block@1.1.0/dist/steam-emerge.js" integrity="sha384-PUXKVdqPLk7akL4rVn2ozcfToQqu5RLDUZ7Xamn074ilP5U/fIwla1lVOJkihDv+" crossorigin="anonymous" defer></script>
<script src="https://cdn.jsdelivr.net/npm/steam-block@1.1.0/dist/steam-block.js" integrity="sha384-iQB69ION+fOI85hIazKAsDqsORX4sV3IemwxcTiqslH/JsGXlJly9as9oMh12ob8" crossorigin="anonymous" defer></script>
```

That's the whole installation. All layout CSS is generated by the component itself into its Shadow DOM at runtime, scoped to each `<steam-block>` instance.

## Quick usage

```html
<steam-block type="split" media="fluid" order="flip">
  <div slot="content">
    <h1>Welcome to Steam Block</h1>
    <p>Flexible layouts made simple.</p>
    <a role="button" href="#">Get started</a>
  </div>
  <img slot="media" src="your-image.jpg" alt="">
</steam-block>
```

`type="split"` picks the side by side template, `media="fluid"` lets the media bleed past its container to the viewport edge, `order="flip"` swaps which side the media sits on. Everything else, borders, blend modes, masks, aspect ratios, column widths, is a `--steam-block-*` CSS custom property layered on top. See [Usage](https://steam-block.stimulies.be/documentation/usage/) for the full walkthrough.

## What it gives you

- Two named slots, `content` and `media`, that accept any markup you like: headings, buttons, `<img>`, `<video>`, `<iframe>`, inline SVG. The component only controls layout, it never restyles what you put inside it.
- Two layout templates: `split` (content and media side by side) and `hero` (content overlaid on a media background).
- Every visual detail exposed as a CSS custom property, no JS API or configuration object to learn.
- Every internal box exposed as a part, so `::part()` can style it with any CSS property: hover states, animations, `backdrop-filter`. Optional, new in 1.1.0.
- `media="fluid"` breaks the media out to the true viewport edge using the element's actual rendered position, so it holds up inside a sidebar, a grid column, or any off center layout, not just a centered one.
- An optional companion script, `steam-emerge.js`, for scroll triggered reveal animations, plain class toggling that plugs into your own CSS or into Animate.css / AOS.
- Zero dependencies, zero build step to consume it.
